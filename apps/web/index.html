PROJECT OVERVIEW

项目概览

本项目将从服务器环境检查开始，逐步完成模型部署、 接口封装、网页接入和性能评测。

项目目标

在Linux服务器上部署开源大语言模型， 并将模型封装为可以通过HTTP请求调用的服务。

当前阶段

已完成服务器环境检查，准备创建独立Conda环境。

技术路线

Linux → Conda → PyTorch → Transformers → Qwen → FastAPI → Web Application

SERVER ENVIRONMENT

服务器运行环境
